# Moect 1.2.6

本次更新主要改善微信连接和图片读取、导出。

- **连接更稳妥**：修复补查本地保留会话时，部分消息缺少类型名称导致连接失败的问题。
- **图片重试生效**：在微信中打开图片后，点击预览中的“重试读取”，会重新尝试获取并严格校验图片解密材料。
- **图片密钥识别改进**：结合近期缓存样本交叉验证，减少旧图或损坏文件对识别的干扰。
- **缩略图兜底更完整**：识别更多高清图和缩略图文件名；原图缺失或无法解密时，显示并导出本地可用缩略图。

图片能否恢复仍取决于本地缓存和可用的解密材料。软件会保留未能解密的原文件及具体状态说明。

## 下载与升级

- **安装版**：下载 `Moect-1.2.6-Setup-x64.exe`，可选择安装位置和是否创建桌面快捷方式。
- **便携版**：下载 `Moect-1.2.6-Windows-x64.zip`，完整解压后运行 `Moect.exe`，保留同级 `_internal` 目录。
- **软件内更新**：已有在线更新功能的版本可点击左下角下载按钮，使用对应的安装版或便携版更新包。网络受限时，可从本页手动下载升级。

Windows 10 1809+ / Windows 11，64 位。升级保留已有配置、任务和聊天归档；已有 HTML 归档中的图片需要重新导出才能应用本次改进。
