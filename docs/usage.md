# Moect 使用指南

## 安装与升级

从 [Releases](https://github.com/mofan6/Moect/releases/latest) 下载 `Moect-1.1.5-Setup-x64.exe`，双击后选择安装位置，并勾选是否创建桌面快捷方式，再点击“安装”。软件默认安装在当前用户的 `%LOCALAPPDATA%\Programs\Moect`，可自行更改，无需预装 Python 或 Node.js。缺少 WebView2 时，安装器通过 Microsoft 官方引导程序自动安装，需要网络连接。

升级前请等待导出任务完成并关闭 Moect。覆盖安装保留用户配置、聊天快照、媒体缓存及历史任务。卸载只移除软件，不删除这些数据或聊天导出。

便携压缩包可解压后运行 `Moect.exe`，保留同级 `_internal` 文件夹。包内不附带使用说明和修复说明，需要时可在项目首页或源码中查看。

## 连接与预览

先登录 Windows 微信，再点击“连接微信”。选择账号后，Moect 获取本地读取凭据，整理聊天快照，并显示好友和群聊。微信版本或进程权限不同可能影响连接；确有权限不足提示时，可退出软件后以管理员身份启动。

也可在设置中打开已有解密备份。演示模式使用完全虚构的记录，便于先了解界面。

点击整行会话直接进入预览，右侧“导出”按钮可创建任务。“批量选择”用于同时导出多个会话。

## 导出与阅读

支持 HTML / JSON / JSONL / TXT / CSV / Markdown，可选择导出时间和关键词。

导出内容可选择：包含系统消息、快速导出、不导出图片/动画表情、不导出视频、不导出语音、仅保留文件元数据以及导出头像。

快速导出保留消息和卡片信息，跳过所有资源与头像。单项资源开关同样阻止本地文件复制、网络下载、解密和转码，适合视频较多或磁盘空间有限的会话。跳过图片也会跳过卡片缩略图，头像由单独开关控制。设置会继续作用于转发和引用；主动跳过的资源有单独状态，不计为缺失或失败。

HTML 打开后直接进入聊天记录，不再经过归档目录页。批量 HTML 导出在聊天页顶部提供会话切换。顶栏右下角箭头可收起或展开顶栏，筛选条件会保留。短消息气泡随内容收紧，长链接在气泡内换行。查看器支持关键词和发送者搜索、北京时间起止时间筛选及“显示全部”；只能筛选本次已导出的消息。

图片和表情点击本身即可查看；分享卡片展示可用标题、说明、缩略图及来源。已保存的文件可从卡片下载。转账卡片只展示历史消息中的金额和状态，不提供支付操作。合并转发会生成独立 HTML 页及 JSON、TXT 副本。

**移动或分享归档时，请复制完整导出文件夹。** HTML 依赖消息分片和本地资源，单独移动 HTML 会导致媒体或消息缺失。新版查看器只用于新导出，已有文件不会被自动重写。

## 资源缺失

导出页顶部会列出已保存、缺失、未解密、不支持及校验失败的资源数量，并提供资源明细。原图尚未下载、微信已清理缓存、凭据不可用或远端资源失效时，不能保证恢复完整资源。

## 存储位置

新安装默认使用 `%LOCALAPPDATA%\Moect` 保存配置与快照。如果发现旧版 `%LOCALAPPDATA%\WeChatExporter\config.json`，会继续沿用旧数据目录。默认新导出路径为 `文档\Moect\exports`，自定义位置不变。不要分享读取凭据、密钥文件或解密快照。
