# Moect 1.2.5

## 新增功能

- **会话分类管理**，支持按好友、群聊、公众号／服务号及其他会话分类查看和批量导出。
- **批量导出取消数量限制**，支持一次选择更多会话，按队列依次处理。支持发现并导出已删除好友在本地保留的聊天记录。
- **新增 Excel 导出**，方便整理和统计聊天记录，支持长消息和大记录量。
- **新增 ZIP 压缩与 AES-256 密码加密**，会话、朋友圈和表情包均可使用。默认关闭，选项和设置过的密码可以记忆。
- **新增打印与保存 PDF**，聊天和朋友圈 HTML 可按当前筛选条件打印。
- **新增缓存管理与空间统计**，支持迁移缓存位置、清理过期快照及可再生成缓存，查看缓存占用、导出体积和媒体分类占用。

## 阅读与使用体验优化

- **会话预览支持本机可用的图片、动画表情和语音**，图片可点击放大查看。
- **升级 HTML 图片查看器**，打开时自动适应窗口，支持以鼠标位置为中心缩放、拖动和切换图片。长篇聊天新增输入页码跳转。
- **完善连接提示与诊断**，按阶段显示连接状态和失败原因，支持导出脱敏诊断信息，改进微信数据目录识别。
- **更新界面与动效**，新增圆形扩散的亮暗切换动画，统一底栏三个按钮的悬浮效果，优化设置页分区、窗口尺寸和弹窗布局。
- **改善兼容性与稳定性**，修复部分文本消息识别错误、引用正文预览重复等问题，改进部分 SILK 语音转码、中文及特殊字符路径支持，以及任务和缓存处理。

HTML 查看器的新交互会应用于新导出的文件。

## 下载与升级

- **安装版**，下载 `Moect-1.2.5-Setup-x64.exe`，可选择安装位置和是否创建桌面快捷方式。
- **便携版**，下载 `Moect-1.2.5-Windows-x64.zip`，完整解压后运行 `Moect.exe`，并保留同级 `_internal` 目录。
- **文件校验**，`SHA256SUMS.txt` 提供安装包和便携版的 SHA-256 校验值。

适用于 Windows 10 1809 或更新版本、Windows 11 x64，面向 Windows 微信 4.x。安装版按需准备 Microsoft Edge WebView2，便携版使用系统已安装的 WebView2。

安装版可覆盖安装升级，便携版可退出软件后将完整程序覆盖到原目录。配置、任务、聊天快照和已有导出文件会继续保留。压缩与加密可在各导出页面的“更多设置”中开启。
