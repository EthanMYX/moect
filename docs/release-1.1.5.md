Moect 1.1.5

## 下载

- **Moect-1.1.5-Setup-x64.exe**：中文安装包，可选择安装位置和桌面快捷方式。
- **Moect-1.1.5-Windows-x64.zip**：便携版，完整解压后运行 Moect.exe，保留同级 _internal 目录。
- **Moect-1.1.5-Source.zip**：对应源码、构建脚本和许可证。
- **SHA256SUMS.txt**：以上三个文件的 SHA-256 校验值。

## 更新内容

- 修复连接时 head_img_md5 等字段包含二进制内容造成的 UTF-8 解码异常。
- 导出可选择系统消息、快速导出、跳过图片/动画表情、视频、语音、文件内容及头像。
- 跳过资源在本地复制、网络下载、解密和转码前生效，同时覆盖引用回复与合并转发；保留消息及已有元数据，主动跳过状态不计为下载失败。
- HTML 短消息气泡随内容收紧；顶栏支持收起和展开，箭头随状态旋转并保留筛选条件。
- 修复软件预览里长链接超出气泡的问题。
- 便携包移除使用说明和修复说明文件，相关文档可在项目首页及源码中查看。

原有 HTML 需要重新导出才能应用新的查看器样式。升级保留用户配置和聊天数据。

## 环境与检查

Windows 10 1809+ / Windows 11 x64，面向微信 4.x。安装版在缺少 WebView2 时自动准备运行环境，需要联网；便携版需要系统已安装 WebView2。

25 项合成数据库/资源测试通过，覆盖六种格式、导出桥接、资源跳过与转发引用；后续界面修复完成静态检查和构建。未使用反馈用户的真实聊天记录进行验证，也未执行桌面界面回归测试。
