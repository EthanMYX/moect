# 公告与在线更新

Moect 1.2.0 内置独立的公告与更新通道。聊天数据在本机处理；通道只分发公开公告和软件更新，不接收聊天数据库或导出内容。

## 用户端

- 每次启动联网检查，也可通过左下角入口手动检查。
- 未读公告在入门教程和其他弹窗关闭后展示，支持 Markdown、链接与图片。前台阅读两秒后可确认，已读状态只保存在本机，新公告独立提醒。
- 仅当发布版本严格高于本机版本时显示更新圆点；相同和更低版本不提示。发现更新不会自动打开更新弹窗。
- 下载完整软件包并校验大小与 SHA-256，分片资源逐片校验后合并。用户确认后，由独立更新组件等待旧进程退出并执行升级。
- 安装版沿用原目录覆盖安装，便携版替换受管理的程序文件；保留用户配置、任务、快照及已有归档。任务进行中不能开始安装。
- 从源码运行可以检查与下载，不能通过更新器覆盖源码目录。

1.1.5 及更早版本需要手动安装一次包含在线模块的新版本，之后才可使用软件内更新。

## 信任与资源

`ui/online-config.json` 只包含分发地址、公开验签公钥和允许的主机。签名使用 Ed25519，客户端校验有效期、序号、版本及资源摘要；作者私钥不进入发行包。Markdown 禁止原始 HTML 与脚本，公告图片经过摘要、格式和大小校验后在本机展示。

版本按数字段比较，例如 1.10.0 高于 1.9.0。系统要求按实际 Windows 内部版本判断；当前桌面程序面向 Windows 10 1809+ / Windows 11 x64。

## 内容撤回与删除

发布中心可撤回公告或更新，并保留作者内容；永久删除先停止签名清单中的分发，再清理没有被其他条目引用的资源。客户端下次成功联网检查时同步，不重复提示已撤回公告，不继续使用失效更新。

安装前主程序和独立更新组件分别重新核对最新签名清单。无法联网确认时暂停安装，保留有效下载供后续重试。撤回不会远程卸载已经安装的软件，也不会删除用户自行保存的归档。

## 独立部署

服务可使用静态 HTTPS 托管与对象存储。当前实现支持 Cloudflare R2，通过独立域名分发清单、公告图片与更新分片。部署时应使用独立的命名空间和密钥，发布者在本机保存签名私钥与服务授权；客户端只持有公钥。

作者工具说明见 [发布中心](publisher.md)。GitHub Releases 与软件内通道分别发布，在 GitHub 上传附件不会自动修改在线公告或更新清单。
