# Moect 发布中心

发布中心是独立的作者工具，源码入口为 `publisher_app.py`，界面入口为 `frontend/src/publisher-main.tsx`。公开发行附件提供用户端软件；作者可参考源码构建自己的发布工具与通道。

## 发布公告与更新

- 公告：填写标题与正文，可插入本机 PNG、JPEG、GIF、WebP 图片，支持 Markdown。选择有效期，检查右侧预览并确认发布。
- 更新：填写真实版本号，选择安装 EXE、便携 ZIP 或两者，填写文字/链接说明，检查软件包后确认发布。
- 新版本必须高于通道当前版本。安装包真实 Windows 版本、便携程序清单、更新组件与客户端公钥均需一致。
- 图片和软件包先上传，最后发布签名清单。更新包按最多 20 MiB 分片，并在公开清单中记录大小和摘要。
- 草稿保存在本机，关闭窗口不会发布草稿。每次正式发布都需在确认窗口中执行。

## 发布记录

可查看线上内容、撤回、永久删除，以及继续清理未完成的云端资源。撤回保留原内容；删除先停止分发，再移除不再被引用的资源。共享资源保留到最后一处引用删除。失败清理可重试，不重复提交发布。

客户端下次成功检查时同步，停止展示被撤回的公告和使用失效更新。用户的既有聊天归档与已安装软件不受远程删除操作影响。

## 作者资料

本机资料默认位于 `%USERPROFILE%/.moect-publisher`，包含草稿、图片、操作记录、原始 Ed25519 签名私钥和服务配置。旧目录只在原私钥匹配时迁移，已有文件不覆盖。服务授权使用本机已有凭据，不包含在 EXE 或源码中。

换电脑时恢复原作者资料并重新完成服务授权。不能用新私钥直接替换原通道私钥；公开客户端仅信任其内置公钥。

## 界面与运行

发布中心采用紫色与鸿蒙字体，支持深浅色、窗口位置记忆、Markdown 实时预览。独立持久 WebView2 目录用于界面运行；启动时显示原生加载页面，界面与本机接口就绪后展示编辑器，异常时有限重试或重建浏览器控件，后台任务不重复提交。

本机 `startup-diagnostic.json` 仅记录阶段、错误类别、进程及重试次数，不记录正文、图片、私钥或服务授权。

## 构建与验证

在 frontend 目录执行 `npx tsc --noEmit` 和 `npx vite build --config vite.publisher.config.ts`，再使用开发 Python 执行 `build_publisher.py`。生成程序不含作者凭据与微信读取器。

`--self-check REPORT` 执行只读身份、授权及公网清单检查；`--gui-check REPORT` 同时验证真实界面就绪。验证模式可附 `--gui-fault reload` 或 `--gui-fault recreate` 检查恢复，并禁止发布、撤回和删除。

后端测试在 `tests/test_publisher.py`、`tests/test_revocations.py`，启动与界面测试在 `tests/test_publisher_startup.py`、`tests/test_publisher_ui.py`；均使用临时资料和模拟服务。
