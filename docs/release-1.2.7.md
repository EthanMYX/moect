# Moect 1.2.7

本次更新重点改善会话与朋友圈的图片读取。

- **新增“恢复图片读取”**：会话页与朋友圈页提供后台恢复入口，使用当前微信账号的近期缓存验证图片密钥，支持从任务页取消。恢复成功后自动刷新预览。
- **补查本地图片**：会话中的“重试读取”会进一步查找同账号的缓存及附件，减少本地文件存在却未被找到的情况。
- **聊天表情缓存复用**：复用表情包功能的本地缓存和解码逻辑，改善表情在聊天预览、导出中的读取。
- **朋友圈状态更准确**：区分图片未缓存、缺少解密材料、文件损坏或格式限制，资源明细记录具体原因，避免统一误报为“缺失”。
- **任务配合更完善**：恢复任务与退出登录、切换账号、缓存管理及软件更新协调，候选密钥经过完整验证后才保存。

## 图片仍未显示时

保持电脑微信登录，在微信中打开需要的图片，然后点击 Moect 页面右上角的“恢复图片读取”。完成后重新查看预览，必要时再点消息下的“重试读取”。已生成的 HTML 需要重新导出。

图片恢复仍取决于本机缓存与可用解密材料；软件无法还原本机没有保存、远端也已失效的原图。

## 下载与升级

- **安装版**：下载 `Moect-1.2.7-Setup-x64.exe`，可选择安装位置及是否创建桌面快捷方式。
- **便携版**：下载 `Moect-1.2.7-Windows-x64.zip`，完整解压后运行 `Moect.exe`，保留同级 `_internal` 目录。

支持 Windows 10 1809+ / Windows 11，64 位。升级保留已有配置、任务和聊天归档。
